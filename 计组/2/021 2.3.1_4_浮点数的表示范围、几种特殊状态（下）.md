## 二、 机器零 (Machine Zero) 与 下溢 (Underflow)

### 1. 机器零的表示

当一个数值极度逼近于 0，乃至超出了底层硬件所能表示的最小极限时，运算结果会被直接存储为**真值 0 (机器零)**。

- **特征**：**阶码全 0，尾数全 0**。
- **区分正负零**：逻辑上 $+0$ 和 $-0$ 是等价的，唯一的区别在于符号位 `S`。
  - **$+0$**：`0 00000000 00000000000000000000000` (全 0)
  - **$-0$**：`1 00000000 00000000000000000000000` (符号位为 1，其余全 0)

### 2. 什么是下溢 (Underflow)？

如果运算结果小于最小规格化数，系统首先会尝试用“非规格化数”去表示。如果该数值小到连非规格化数都无法容纳，最终跌入**机器零**区间，这被称为**下溢 (Underflow)**。

- **硬件响应**：只有当结果下溢到**机器零**时，处理器的浮点运算单元才会将“下溢异常标志位 (UE - Underflow Exception)”置 1。
- **系统响应**：与上溢一样，IEEE 754 规定系统**默认不响应下溢异常**，程序不会崩溃，而是按 0 继续执行。

## 三、 非规格化浮点数 (Denormalized Numbers)

这是介于“最小规格化正数”和“机器零”之间的一个过渡地带，专门用来表示**极端微小的数值**，起到平滑过渡的作用。

### 1. 核心解读规则 (🚨极易错考点)

- **状态特征**：**阶码全 0，尾数不全为 0**。
- **规则 A (隐藏位变了)**：尾数的小数点前隐含的不再是 1，而是 **0**。即尾数形式为 `0.xxxx...`。
- **规则 B (固定阶码真值)**：阶码全 0 **不能**按常规无符号数减去偏置值处理！IEEE 754 强制规定：
  - **Float 型**：非规格化数的阶码真值固定为 **$1 - 127 = \mathbf{-126}$** (注意不是 -127！)。
  - **Double 型**：非规格化数的阶码真值固定为 **$1 - 1023 = \mathbf{-1022}$**。

### 2. 极值推导 (以 Float 为例)

#### A. 最小非规格化正数 (最接近 0 的数)

- **要求**：尾数最小，即最后一位为 1，其余全 0。
- **科学计数法**：$+0.000...01_2 \times 2^{-126}$
- **十进制表示**：$2^{-23} \times 2^{-126} = \mathbf{2^{-149}}$

#### B. 最大非规格化正数 (紧挨着最小规格化数)

- **要求**：尾数最大，即 23 位全为 1。
- **科学计数法**：$+0.111...11_2 \times 2^{-126}$
- **十进制表示**：$(1 - 2^{-23}) \times 2^{-126} = \mathbf{2^{-126} - 2^{-149}}$

## 四、 真题演练 (2023年统考 第14题)

**题目**：已知某 float 型变量的机器数为 `0x00400000`，求其表示的真值。

### 💡 解析步骤：

1.  **展开二进制**：`0x00400000` = `0 00000000 10000000000000000000000`
2.  **划分区域**：`0` (符号位) | `00000000` (阶码) | `100000...0` (尾数)
3.  **判断类型**：阶码全 0，尾数不全为 0 $\rightarrow$ **非规格化数**。
4.  **按规则解读**：
    - 符号位 `0` $\rightarrow$ 正数。
    - 阶码真值 $\rightarrow$ 固定为 **$-126$**。
    - 尾数还原 $\rightarrow$ 补上前导 0：`0.100...0_2`。转为十进制为 $0.5$ (即 $2^{-1}$)。
5.  **计算最终真值**：$+ 2^{-1} \times 2^{-126} = \mathbf{2^{-127}}$。（答案选 A）

## 五、 无意义数 NaN (Not a Number)

当出现无法在数学上定义实数结果的非法运算时，计算机会返回 **NaN**。

- **特征**：**阶码全 1，尾数不全为 0**。(符号位 0/1 均可)
- **触发场景**：
  - `0.0 / 0.0`
  - `sqrt(-1.0)` (负数开平方)
  - `inf - inf` (无穷减无穷)
- **变态考点提醒 (无穷 vs NaN)**：
  - `非零数 / 0.0` (如 $1.0 / 0.0$) $\rightarrow$ **$\pm\infty$ (无穷大)**
  - `0.0 / 0.0` $\rightarrow$ **NaN (非数)**

> 编程语言（如 C 语言的 `math.h`）提供了 `isnan(x)` 和 `isinf(x)` 函数，帮助程序员在不中断程序的前提下，手动捕获并处理这些特殊异常状态，极大提升了程序的容错性。

## 六、 本节总结与 Double 型扩展清单

本节课我们彻底攻克了浮点数数轴上的“边角料”地带：

- **规格化数**：隐藏 `1`，阶码真值 = 无符号值 - Bias。
- **非规格化数**：隐藏 `0`，阶码真值固定为 $1 - Bias$（专门解决极小数的平滑过渡）。
- **机器零**：全 0。
- **无穷大**：全 1 阶码，全 0 尾数。
- **NaN**：全 1 阶码，非零尾数。

# 计算机组成原理：总线标准与发展史

> **导语**
> 各位同学大家好，在这个小节中，我们将带大家了解计算机底层的**总线标准**。
> 总线的种类繁多，为了让不同硬件厂商（如造 CPU 的、造显卡的、造硬盘的）生产的设备能够插在同一块主板上完美协同工作，就必须制定统一的“物理和逻辑契约”，这就是总线标准。本节课我们将从宏观层级对总线进行分类，并梳理系统总线、局部总线和设备总线从**“并行到串行”**的演进历程。这部分内容主要以选择题的形式考察。

---

## 一、 总线标准的制定思想

制定总线标准，本质上就如同软件开发中定义“接口规范”一样。通过一套完整的约束条件，使得不同厂商独立开发的硬件部件可以在物理和电气层面无缝对接。

一个完善的总线标准通常会规定以下细节：

1.  **数据传输格式**：采用串行还是并行？每次传输多少位（如 32 位、64 位）？
2.  **线序复用机制**：地址线和数据线是否共用物理引脚（先传地址，后传数据）？
3.  **定时与时序**：采用同步定时还是异步通信？总线周期包含几个时钟周期？
4.  **工作频率与上限**：规定必须达到的最低或最高总线时钟频率，各设备必须能跟上这个节奏。
5.  **电气特性**：规定什么电压范围代表高电平（逻辑 0），什么电压范围代表低电平（逻辑 1）。

## 二、 总线在系统架构中的分层 (分类)

根据总线在主板上连接的**硬件层级**和**地理位置**，可以将总线分为三大类：

```mermaid

        NB <--> |<b>局部总线</b> <br> (如显卡, 高速网卡)| HIGH_DEV[高速硬件部件]
        NB <--> |内部总线| SB[南桥芯片 <br> (低速枢纽)]
        SB <--> |<b>设备总线 / 通信总线</b> <br> (如鼠标, 键盘, 打印机)| SLOW_DEV[慢速 I/O 设备]

    style SB fill:#d9ead3,stroke:#6aa84f
```

1.  **系统总线 (System Bus)**：**直接与 CPU 相连**的总线。它连接 CPU 与北桥芯片、主存等核心枢纽。由于直通大脑，它的速度要求是全系统最快的。
2.  **局部总线 (Local Bus)**：**不与 CPU 直接相连**，而是连接在北桥芯片上。主要用于挂载对带宽要求极高的高速外设，如独立显卡、高速固态硬盘等。
3.  **设备总线 / 通信总线 (Device/Communication Bus)**：通常连接在南桥芯片上，用于连接相对慢速的外部 I/O 设备（如鼠标、键盘、外接打印机等）。

## 三、 经典总线标准的演进历史 (重点梳理)

计算机总线发展史的一条核心明线是：**从并行传输全面转向串行传输**。

### 1. 系统总线的发展

- **ISA / EISA (早期并行)**：80 年代 IBM 提出，工作频率极低（约 8MHz），且由 CPU 直接控制，容易拖累 CPU。
- **FSB (前端总线, 并行)**：Intel 为奔腾时代提出的系统总线标准，速度有了显著提升。
- **QPI (QuickPath Interconnect, 串行)**：Intel 现役的高速串行系统总线，彻底摒弃了传统的 FSB 架构。

### 2. 局部总线的发展 (显卡/网卡总线)

- **VESA (并行)**：为早期图形操作系统（如 Win95）诞生，但致命缺陷是工作频率仍受 CPU 控制，无法独立提速。
- **PCI (Peripheral Component Interconnect, 并行)**：一代神级总线！摆脱了对特定 CPU 的依附，由北桥独立控制，适应性极强，曾经统治了整个 90 年代。
- **AGP (并行)**：基于 PCI 标准修改的“加速图形接口”，专门为当时日益复杂的 3D 显卡定制。
- **PCIe (PCI Express, 串行 $\star$)**：21世纪的颠覆级标准。
  - **串行点对点传输**：放弃了容易受干扰的并行总线，改用差分信号串行传输，频率可以做到极高。
  - **独立通道不排队**：每个 PCIe 设备拥有独享的点对点通道，不再像 PCI 那样多个设备争抢一根总线。
  - **支持多通道 (x1, x4, x16)**：通过组合多条串行通道同时发送多个数据包来实现高速率。
  - **全双工 & 热插拔**：支持同时收发，支持设备带电插拔。

### 3. 设备总线的发展 (外部通信接口)

- **RS-232C (早期串行)**：古老的串口标准（每秒几十KB），最早用于连接针式打印机，速度极慢。
- **SCSI (并行)**：为扫描仪、早期高速存储设备设计的并行接口。
- **PCMCIA (并行)**：90年代笔记本电脑专用的便携式存储扩展卡接口。
- **USB (Universal Serial Bus, 串行 $\star$)**：
  - **抗干扰极强**：采用**差模信号**（两根线传 1 个比特，对比电压差）和**双绞线**物理缠绕设计，使得抗电磁干扰能力拉满，工作频率可飙升。
  - **可扩展性强**：支持菊花链/集线器拓扑，一个 USB 控制器理论上可挂载 127 个外设。支持热插拔。

### 4. 硬盘专属总线的发展

- **IDE / PATA (并行)**：即早期的 ATA 并行排线，排线又宽又扁，极易干扰，速度上限被锁死在 100MB/s 左右。
- **SATA (串行 $\star$)**：引入串行差分传输技术，速度发生质的飞跃（SATA 3.0 可达 600MB/s 级）。

## 四、 【核心考点释疑】为何串行总线能干掉并行总线？

在 90 年代前，提升总线速度的思路都是“增加信号线数量（加宽）”。但步入 21 世纪，所有高速总线（PCIe, USB, SATA）**全部变成了串行**。

**并行总线的致命伤：高频下的电磁串扰与延迟对齐**

1.  **线间电磁干扰**：当几十根信号线紧密排布且工作在超高频率时，线与线之间的电磁干扰极其严重，导致信号极易失真。因此并行总线的时钟频率被物理法则锁死，无法继续做高。
2.  **多路同步对齐困境**：在极高的时钟频率下，哪怕这几十根线在主板上的长度相差了哪怕 1 毫米，电信号到达终点的时间也会产生极微小的时差。在同步定时机制下，这足以导致数据包在接收端完全错位、乱码。制造完美等长的密集线路，工艺成本极其高昂。

**串行总线的破局之道**

1.  **差模信号抗干扰**：仅用两根线一正一负传递 1 个比特，无惧外界电磁干扰。
2.  **无长度对齐顾虑**：因为是单通道顺次发送，不需要考虑多根线同时到达的问题。
3.  **频率狂飙**：因为排除了上述物理干扰，串行总线的时钟频率可以被推到极高（GHz级别）。
4.  **宏观多通道组合**：像 PCIe x16，实际上是安排了 16 条独立的串行通道。它们各自独立地超高速发包，接收端收到后再把这 16 个包重新组装起来。这与传统意义上的“并行总线”有着本质的区别。

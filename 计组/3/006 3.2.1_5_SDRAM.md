# 计算机组成原理：SDRAM (同步动态随机存取存储器)

> **导语**
> 本节课我们将探讨 **SDRAM（同步 DRAM）**。现代计算机和手机中的内存条基本都是基于 SDRAM 技术的（如大家熟知的 DDR4、DDR5）。我们将了解 DRAM 技术的发展脉络，并重点对比传统的**异步 DRAM** 与现代的**同步 DRAM** 之间的核心区别，尤其是“同步”机制如何大幅提升 CPU 的工作效率。

---

## 一、 DRAM 技术的演进脉络

DRAM 的发展一直朝着“存取速度更快、更节能、更稳定”的方向演进。了解这些术语有助于在考题中准确识别。

- **传统异步 DRAM** (1996年以前)：主存与 CPU 节奏不同步，存在盲等现象。
- **SDR SDRAM** (单倍数据率同步 DRAM，约1996年)：引入同步机制，一个时钟周期传 1 次数据。
- **DDR SDRAM** (双倍数据率，约1998年)：一个时钟周期传 2 次数据（利用时钟的上升沿和下降沿）。
- **DDR2 / DDR3 / DDR4 / DDR5 ...**：随着技术演进，代际不断更新，速度翻倍，功耗降低。
  - _注：内存条代际与 CPU 平台是强绑定的。例如某代 CPU 主板仅支持 DDR4，无法插入 DDR5 内存条。_

---

## 二、 异步 DRAM vs 同步 DRAM (核心考点)

SDRAM 中的 "S" 代表 **Synchronous (同步)**。两者的核心区别在于**时序基准**和对 CPU 效率的影响。

### 1. 传统的异步 DRAM (Asynchronous DRAM)

- **交互方式**：CPU 与主存之间**没有统一的系统时钟节拍**。
- **工作流问题**：
  - CPU 发出读/写命令后，由于主存速度远慢于 CPU，主存需要一段时间准备数据。
  - 在此期间，由于没有确定的时间基准，CPU 只能陷入**“盲等”**，必须不断地**轮询检查**主存的就绪状态（类似不停地问“好了没？”）。
- **缺点**：等待时间不确定，严重浪费 CPU 的计算资源。

### 2. 同步 DRAM (SDRAM - Synchronous DRAM)

- **交互方式**：CPU 与主存的读写动作受**统一的系统时钟控制**，有了共同的节奏。
- **工作流优势**：
  - CPU 将地址信息（读哪里）和控制信息（读还是写）发送给主存。
  - 主存将这些信息**锁存**。
  - 由于双方节奏同步，CPU 明确知道主存需要“**确定的几个时钟周期**”后才能准备好数据（例如，约定好 5 个时钟周期后交货）。
  - 在此确定性的等待期间，CPU 不必轮询，可以**切换去执行其他程序或任务**，时间到了直接回来取数据即可。
- **优点**：消除了盲等，极大提升了 CPU 的整体工作效率。

## 三、 突发传送方式 (Burst Transfer)

除了同步机制，SDRAM 的另一大重要特性是原生支持**突发传送**。

### 1. 突发传送的概念

CPU 只需要向主存发送**一次**起始地址和要读取的数据量（如连续 $N$ 个字节），主存就能在接下来的几个时钟周期内，**连续不断地**将同一行中的多个字打包传回给 CPU，而不需要 CPU 每次读一个字都发一次地址。

### 2. 对比差异

- **早期异步 DRAM**：通常不支持突发传输。读一个字，发一次地址；读 16 个字，要发 16 次地址，连续传输能力极弱。
- **后期异步 DRAM (如 EDO DRAM)**：开始支持类似突发的传输方式。
- **SDRAM (同步 DRAM)**：完美支持并固化了突发传输标准。

> 💡 **考点预告**：
> 突发传输在计算机中应用极为广泛。在未来的章节中，大家会看到在 **Cache 与主存的数据块交换**，以及 **DMA 设备与主存的数据传输** 中，都高度依赖并使用了突发传输技术。

## 四、 真题实战演练

> **【2015年 统考第17题】**
> 下列存储器中，在工作期间需要周期性刷新的是 ( )。
> A. SRAM
> B. SDRAM
> C. ROM
> D. Flash

**解析：选 B。**

- 无论前缀加上 SDR、DDR 还是 SDRAM，只要其后缀核心是 **DRAM**，就决定了它的底层物理存储元件是**电容**。
- 只要是电容，就会有**自然漏电**的物理特性（原本存的比特 `1` 电荷会流失变成 `0`）。
- 因此，所有的 DRAM（包括本题的 **S**DRAM）都必须进行**周期性定时刷新**以防数据丢失。

## 一、 考研大纲要求与考察方式定位

在 408 考研中，关于“机器级代码”的考察具有以下鲜明特点：

1.  **只考 x86 汇编**：国内高校的汇编课程多以 x86 为主，因此考研默认考察 x86 汇编。如果出现 ARM 或 MIPS 汇编，题目必然会给出详细的注释说明。
2.  **“阅读理解”为主**：题目通常会给出一小段 C 语言代码及其对应的汇编代码。你需要能看懂常见的汇编指令（如 `MOV`），以及选择结构 (`if-else`)、循环结构 (`for/while`) 和函数调用在底层是如何实现的。
3.  **深度考察点**：有可能会让你分析某条具体机器指令的格式（操作码占几位、地址码占几位、寻址方式是什么），这就与前几节学习的指令格式知识无缝衔接了。
4.  **绝对不考手写汇编**：请吃下这颗定心丸，你不需要具备把 C 语言人工翻译成汇编语言的能力。

## 二、 寻址探秘：数据到底藏在哪里？

一条指令的核心任务是对数据进行处理。那么，参与运算的数据（操作数）从哪里来？又该如何用汇编语法来表达？
在 x86 体系下，操作数的来源无非三种：**寄存器**、**主存 (内存)** 或 **指令本身 (立即数)**。

我们以最基础的数据传送指令 `MOV` 为例：
**语法格式**：`MOV 目的操作数(d), 源操作数(s)`
_作用：将源操作数的值复制到目的操作数中。_

### 1. 数据在寄存器中 (寄存器寻址)

**特征**：直接写出寄存器的名字。

```assembly
MOV EAX, EBX    ; 将 EBX 寄存器中的 32 位数据复制到 EAX 寄存器中
```

### 2. 数据在指令中 (立即寻址)

**特征**：直接给出一个常数（十进制或十六进制，十六进制常以 `H` 结尾）。

```assembly
MOV EAX, 5      ; 将常数 5 (立即数) 复制到 EAX 寄存器中
MOV EAX, 0FFH   ; 将十六进制数 FF 复制到 EAX 中
```

### 3. 数据在主存中 (直接/间接寻址)

**特征**：**必定带有中括号 `[]`**，中括号内装的是内存的物理地址或存放地址的寄存器。中括号前面通常带有 `xxx PTR` 来指明读写的数据长度。

- `DWORD PTR`：双字 (Double Word)，读写 32 比特 (4 字节)。
- `WORD PTR`：单字 (Word)，读写 16 比特 (2 字节)。
- `BYTE PTR`：字节 (Byte)，读写 8 比特 (1 字节)。

```assembly
MOV EAX, DWORD PTR [AF996H]  ; 从物理地址 AF996H 处读取 32 位数据到 EAX
MOV BYTE PTR [AF996H], 5     ; 将数字 5 作为一个字节(8位)写入物理地址 AF996H
MOV EAX, DWORD PTR [EBX]     ; (寄存器间接寻址) 从 EBX 所指向的主存地址读取 32 位数据到 EAX
MOV EAX, [EBX+8]             ; (变址/基址偏移) 省略了长度说明，默认按 32 位读取。地址为 EBX里的值 + 8
```

> _注：如果主存寻址时省略了前面的长度说明词（如 `DWORD PTR`），在 32 位 x86 考题中通常**默认读写 32 比特**。_

## 三、 x86 架构的核心寄存器全家福

要在考试中一眼认出谁是寄存器，你必须熟悉 x86 架构下最核心的 8 个 32位 寄存器。

> 💡 **终极识别特征**：在 32 位 x86 汇编中，寄存器的名字**一律以字母 `E` (Extended, 扩展的) 开头**！

        STACK --> ESP[(ESP: 栈顶指针)]

### 【扩展用法】通用寄存器的灵活拆分

Intel 的设计为了向下兼容早期的 16位 和 8位 系统，允许我们对 `EAX, EBX, ECX, EDX` 这四个通用寄存器进行“部分截取”使用：

- **32 位完整使用**：`EAX`
- **只使用低 16 位**：去掉 `E`，变为 `AX`
- **只使用低 16 位中的高 8 位**：变为 `AH` (High)
- **只使用低 16 位中的低 8 位**：变为 `AL` (Low)

```assembly
MOV AX, BX      ; 将 BX 的 16 位数据复制到 AX 中
MOV AH, BL      ; 将 BL 的低 8 位数据复制到 AH 中
```

_(注：考研中绝大多数情况都是直接使用带 `E` 的完整 32 位形态，遇到不带 `E` 的知道是截断使用即可。)_

## 本节复习要点实战检验

现在，让我们用今天学到的“X光眼”，去透视一段真实的考研真题汇编代码片段：

```assembly
PUSH EBP               ; PUSH 是压栈指令。EBP 是以 E 开头的寄存器。意为：将 EBP 寄存器的值压入堆栈。
CMP DWORD PTR [EBP+8], 1 ; CMP 是比较指令。逗号前有 [] 和 DWORD PTR，说明这是一个 32位 的主存数据，其物理地址为 EBP寄存器的值+8。逗号后是立即数 1。意为：将主存中的值与数字 1 进行比较。
```

看！即使我们还不知道具体的指令功能（如 `CMP` 是怎么比较的），但只要掌握了本节课的知识，我们就能清晰地剖析出每条语句到底在操控哪些数据、数据在主存还是在寄存器、读写了多长的数据。

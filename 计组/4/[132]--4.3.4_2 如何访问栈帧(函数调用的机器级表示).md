# 机器级代码：函数调用栈的数据访问机制

> **导语**
> 各位同学大家好，在上个小节中，我们学习了使用 `CALL` 和 `RET` 指令来实现函数调用时程序执行流的跳转。本节课，我们将深入函数调用栈的内部，探究另外两个核心问题：**为什么栈要倒着画？** 以及在汇编代码中，**CPU 是如何读写栈帧内部的具体数据（如局部变量、参数）的？**
> 掌握了栈底指针 `EBP` 和栈顶指针 `ESP` 的相对寻址技巧，你就能在考研真题中清晰地拆解出函数调用的底层逻辑。

## 一、 函数调用栈的宏观内存布局：为什么“栈倒着画”？

在 32 位操作系统中，每个进程都会拥有 **4GB 的虚拟地址空间**（地址范围从 `0x00000000` 到 `0xFFFFFFFF`）。

- **高地址区 (最高的 1GB)**：预留给**操作系统内核**使用。
- **低地址区 (剩余的 3GB)**：属于**用户进程**空间，用于存放代码、数据等。

**函数调用栈 (Call Stack)** 就位于用户进程空间中靠近顶部（高地址）的位置。
**关键特性**：在 x86 架构中，**栈是向着低地址方向生长的**。

- **栈底 (Bottom)**：位于**高地址**处（因此画在图的**上方**）。
- **栈顶 (Top)**：随着数据的压入，栈顶指针不断向**低地址**方向移动（因此画在图的**下方**）。

```mermaid

            STACK_BODY[函数调用栈区域 <br> 栈往下生长]

```

## 二、 访问栈帧的核心寄存器：EBP 与 ESP

在 CPU 内部，有两个专门用于管理函数调用栈的寄存器。**整个系统中同一时刻只有这一对 EBP 和 ESP**，它们始终标记着**当前正在执行的函数**的栈帧边界。在 x86 体系中，对栈的读写操作**默认以 4 字节 (32 位，即一个 DWORD)** 为单位。

- **`EBP` (Extended Base Pointer，栈底基址指针)**：指向当前函数栈帧的**底部**（高地址处）。通常作为访问局部变量和参数的**基准锚点**。
- **`ESP` (Extended Stack Pointer，栈顶指针)**：指向当前函数栈帧的**顶部**（低地址处），也就是当前栈中最后一个被压入的数据所在的位置。

## 三、 方法一：使用 PUSH 和 POP 指令动态访问

`PUSH` (压栈) 和 `POP` (出栈) 指令是专门用于操作栈顶数据的汇编指令。

### 1. `PUSH` 压栈操作

- **功能**：将数据压入栈顶。操作数可以是立即数、寄存器或主存地址中的值。
- **底层硬件动作**：
  1.  **先移指针**：`ESP = ESP - 4` （由于栈向低地址生长，压入新数据前，ESP 必须先减 4 腾出空间）。
  2.  **后存数据**：将操作数写入此时 `ESP` 指向的主存地址中。

**示例解析**：

```assembly
PUSH EAX          ; 1. ESP-4; 2. 将 EAX 的值写入 [ESP]
PUSH 985          ; 1. ESP-4; 2. 将常数 985 写入 [ESP]
PUSH DWORD PTR [EBP+8]  ; 1. ESP-4; 2. 读出 EBP+8 地址处的 4 字节数据，写入 [ESP]
```

### 2. `POP` 出栈操作

- **功能**：将栈顶数据弹出，并保存到指定位置（寄存器或主存）。
- **底层硬件动作**：
  1.  **先取数据**：将当前 `ESP` 指向的主存数据复制到目标位置。
  2.  **后移指针**：`ESP = ESP + 4` （逻辑上删除栈顶元素，指针退回高地址）。

**示例解析**：

```assembly
POP EAX           ; 1. 取出 [ESP] 的值写入 EAX; 2. ESP+4
POP DWORD PTR [EBP+8]   ; 1. 取出 [ESP] 的值写入主存 [EBP+8] 处; 2. ESP+4
```

> **总结**：`PUSH` 和 `POP` 操作简单，但**只能对栈顶位置进行读写**，无法直接跳跃访问栈中间的数据。

## 四、 方法二：使用 MOV 指令进行任意偏移访问 (★ 最常用)

在实际的函数执行过程中，我们需要频繁访问栈帧中间的局部变量或上面传递下来的参数。此时，使用 `MOV` 指令结合 `EBP` 和 `ESP` 的偏移量，是最灵活、最常见的手段。

### 1. 调整栈顶指针分配空间

函数刚开始执行时，通常会通过减小 `ESP` 的值，在栈中为局部变量**一次性分配好空间**。

```assembly
SUB ESP, 12       ; 将 ESP 的值减去 12。相当于在栈顶向下开辟了 3 个 DWORD (12 字节) 的空位。
```

### 2. 使用 MOV 与偏移量精准打击

此时，`EBP` 和 `ESP` 被固定成了当前栈帧的上下边界。我们可以利用中括号 `[ ]` 加上偏移量，像游标卡尺一样精准访问栈中的任何位置：

- **基于 ESP 向上偏移 (加法)**：

  ```assembly
  MOV [ESP+8], EAX  ; 把 EAX 的值存入 ESP 往高地址数 8 个字节的位置
  MOV [ESP+4], 985  ; 把常数 985 存入 ESP 往高地址数 4 个字节的位置
  ```

- **基于 EBP 向上/向下偏移 (加法/减法)**：
  - `[EBP + 偏移量]`：通常用来向上（高地址方向）越过栈底，**访问主调函数传进来的参数**。
  - `[EBP - 偏移量]`：通常用来向下（低地址方向）在当前栈帧内，**访问本函数的局部变量**。
  ```assembly
  MOV EAX, [EBP+8]  ; 将 EBP 往高地址数 8 个字节处的数据读出，存入 EAX
  MOV [ESP], EAX    ; 将刚才读出的值，直接存入当前的栈顶位置
  ```

### 3. 函数结束时的栈空间回收

函数执行完毕准备 `RET` 之前，需要清理刚才分配的局部变量空间，恢复 `ESP`。

```assembly
ADD ESP, 8        ; 将 ESP 的值加 8。相当于逻辑上销毁了栈顶的 2 个 DWORD (8 字节) 空间，指针向上回退。
```

## 本节复习要点实战检验

在分析 408 考研真题的函数汇编代码时，请在脑海中建立以下空间直觉：

1.  **上下方向感**：画栈图时，**上面是高地址 (栈底)，下面是低地址 (栈顶)**。
2.  **指针移动规律**：
    - **进栈 / 分配空间**：指针**向下**走，数值是**减法** (`SUB ESP, X` 或 `PUSH`)。
    - **出栈 / 释放空间**：指针**向上**走，数值是**加法** (`ADD ESP, X` 或 `POP`)。
3.  **万能的基址锚点 EBP**：在绝大多数编译器的汇编代码中，由于 `ESP` 会随着压栈出栈频繁变动，编译器更喜欢用固定不动的 **`EBP` 作为基准**，加上或减去固定的偏移量来寻找局部变量和函数参数。
